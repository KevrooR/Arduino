# Arduino

Colecao de sketches e experimentos com Arduino -- parte dos meus projetos de hardware hacking.

## Sketches
- **Farol.ino** -- controle de 3 LEDs simulando um semaforo/farol com temporizacao.
- **I2C_scanner.ino** -- teste de comunicacao com display LCD 16x2 via barramento I2C.
- **RFID_Codigo.ino** -- leitor RFID (modulo MFRC522) com display LCD: identifica cartoes cadastrados e exibe uma mensagem correspondente na tela.
- **Tempcerto.ino** / **TesteDisplay.ino** -- leitura de sensor de temperatura e umidade com exibicao dos valores no display LCD.

## Stack
- Arduino (C/C++)
- Bibliotecas: Wire, LiquidCrystal_I2C, SPI, MFRC522
